HOW TO UPDATE
- data/profile.js       : bio, links, stats, education, experience, grants, roles, skills
- data/publications.js  : add a new { citation, year, doi, group } at the top
- data/presentations.js, sessions.js, awards.js, events.js, guided.js : add entries at the top
- js/main.js            : SECTIONS list at the bottom controls section order and nav labels
- css/styles.css        : colours and spacing are variables at the top (:root)
Open index.html in a browser. No build step or server needed.
